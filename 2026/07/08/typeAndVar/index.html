变量

&emsp;&emsp;变量是每个编程学习者必须了解的概念，变量在编程中起到人机桥梁的作用，让我们编程者与计算机之间有共同语言。在我们的视角里，变量是一段有着一定规律的字符(这里指变量名),我们对它进行运算，为它赋值，将它创造，也可以把它从内存中抹除；在计算机的视角里，它将我们眼中变量的名称与计算机内存中的一个地址关联起来，我们使用变量名进行的操作，计算机会根据内存地址找到其背后实际的数据，从而进行计算。C语言中也为我们编程者提供了直接访问内存地址的方法，我们称之为指针。

变量的命名规则

&emsp;&emsp;计算机作为相当暴力的运算机器，它并不能像人类一样知书达理，善解人意，所以与之交流往往需要明确且严格的规范与准则。在C语言中变量的命名需要遵循一下3条规则:

  1. 变量名中包含且仅包含: 小写英文字母、大写英文字母、阿拉伯数字、下划线(_)
  2. 变量名不能以阿拉伯数字开头
  3. 变量名不能与任何C语言保留关键字相同
    &emsp;&emsp;显然这三条规则里前两条作为硬性要求必须遵守，无需任何解释与说明。而第三条规则中的保留关键字是什么呢？

大小写敏感的语言

&emsp;&emsp;C语言是大小写敏感的语言，即就是在编程过程中需要注意大小写的书写，在C语言中”Apple”、”apple”、”APPLE”、”aPPle”、”aPpLe”是完全不同的变量名，而在一些大小写不敏感的语言中这些就是完全一样的没有任何区别

变量名命名社区规范

&emsp;&emsp;虽然只要满足变量名的3条规则就是合法的变量名，但是为了代码更加方便阅读，与便于理解与交流，民间也产生了几种常见的变量名命名规则。常见的有一下3种:

  1. 小驼峰式(使用连贯的单词组成，首个单词首字母不大写，其余首字母均大写)
  2. 大驼峰式(与小驼峰类似，只是首个单词也要首字母大写)
  3. 匈牙利式(过于繁琐与专业，暂不介绍)
  4. 下划线间隔式(python社区推荐的命名规范，这里不做展开)
    以下是一个小驼峰式变量名的示范:
    int numberOfClassmates = 50;
    bool isWeatherClear = false;
    long long int earthSpecies = 120000000000;

运算符

&emsp;&emsp;显然运算是编程中的重要环节，运算就需要用到我们的运算符。不过我们首先要学习的是赋值运算符，就是我们的等于号(=)

声明与赋值

&emsp;&emsp;在程序运行时某个变量的数据类型是在编译时就敲定了，因为计算机需要知道它需要占用多少的内存，所以编程者就需要声明变量。注意:C语言以分号认定语句，每行末的分号标志着一个语句的结束。一下是两个C语言中的声明形式，严格意义上只有第一种是声明，而第二种是C语言支持声明的同时完成赋值，故而两种形式皆可完成生命操作。

数据类型 变量名;
数据类型 变量名 = 初始值;
以下是代码的范例:

int numberOfClassmates;
int numberOfClassmates = 50;

在这个语句中，*”numberOfClassmates”是变量名，“int”*是数据类型，当然如何你有一个已经声明但没有赋值的变量该怎么办呢？

键 = 值
这个”左键右值”的格式是整个编程届都通用的赋值形式，计算机会将右边值里的数据赋给左边的键,就像这样:

int applePicked;
applePicked = 10;

当然右边的值除了直接的数据之外也可以是一个变量名，那么计算机会将右边的变量所存储的值赋给左面的变量中，如下:

int appleWarehouse;
int applePicked = 10;
appleWarehouse = applePicked;

算术运算符

&emsp;&emsp;赋值运算符让我们能把数据放进变量里，但光有数据可不够，我们还得让数据“动”起来——这就轮到算术运算符登场了。算术运算符就是用来做数学运算的符号，它们和我们小学学的加减乘除几乎一模一样，只不过在编程里，乘号不是“×”而是“*”，除号不是“÷”而是“/”，另外还多了一个取余数(取模)的“%”。下表列出了C语言支持的算术运算符：

运算符 含义 示例(假设 a = 10, b = 3)
+ 加法 a + b 结果为 13
- 减法 a - b 结果为 7
* 乘法 a * b 结果为 30
/ 除法 a / b 结果为 3(注意：整数除法会截断小数部分)
% 取模(取余数) a % b 结果为 1

&emsp;&emsp;这里要特别敲黑板：整数除法和浮点数除法是有区别的。如果两个操作数都是整数，那么/执行的是整数除法，结果直接丢掉小数部分(不是四舍五入，是直接截断)。如果你想要精确的小数结果，至少要把其中一个操作数变成浮点数，比如写成 10.0 / 3 或 (float)a / b。

int apple = 10;
int people = 3;
int each = apple / people;      // each 得 3，因为 10/3=3 余 1
float precise = 10.0 / people;  // precise 得 3.333333
int remainder = apple % people; // remainder 得 1，因为 10 除以 3 余 1

&emsp;&emsp;加减乘除可能大家都很熟悉，但取模运算可能大家都不是很熟悉了，但是它在编程中有着很大作用呢~下面是一段完整的质数筛选算法，来体会取模运算的独特魅力:

#include <stdio.h>
#include <stdlib.h>

int n;

int main(void) {
    printf("Input a positive integer n (n >= 2): ");
    if (scanf("%d", &n) != 1 || n < 2) {
        printf("Please input a positive integer greater than or equal to 2.\n");
        return 1;
    }
    int *is_prime = (int *)malloc((n + 1) * sizeof(int));
    int *primes = (int *)malloc((n / 10 + 10) * sizeof(int));
    if (!is_prime || !primes) {
        fprintf(stderr, "Memory allocation failed.\n");
        free(is_prime);
        free(primes);
        return 1;
    }
    for (int i = 0; i <= n; i++) { is_prime[i] = 1; }
    is_prime[0] = is_prime[1] = 0;
    int prime_count = 0;
    for (int i = 2; i <= n; i++) {
        if (is_prime[i]) { primes[prime_count++] = i; }
        for (int j = 0; j < prime_count; j++) {
            int p = primes[j];
            int x = i * p;
            if (x > n) { break; }
            is_prime[x] = 0;
            if (i % p == 0) { break; }
        }
    }
    printf("%d within the range has %d primes:\n", n, prime_count);
    for (int i = 0; i < prime_count; i++) {
        printf("%d", primes[i]);
        if ((i + 1) % 10 == 0 || i == prime_count - 1) {
            printf("\n");
        } else {
            printf(" ");
        }
    }
    free(is_prime);
    free(primes);
    return 0;
}

相信你已经感受到其中的魅力了，那么我们继续学习，条件关系运算符。

关系运算符

&emsp;&emsp;运算不只是做加减乘除，我们经常还需要比较两个值的大小或者判断它们是否相等——这时候就要用到关系运算符。关系运算符的运算结果是一个布尔值(true 或 false)，在C语言中，true 用非零值(通常是1)表示，false 用0表示。

运算符 含义 示例(a=5, b=8)
== 等于 a == b 为 false(0)
!= 不等于 a != b 为 true(1)
> 大于 a > b 为 false
< 小于 a < b 为 true
>= 大于等于 a >= b 为 false
<= 小于等于 a <= b 为 true

&emsp;&emsp;请注意，等于比较用的是两个等号 ==，一个等号 = 是赋值，这是初学者最容易踩的坑。如果你写了 if (a = 5)，编译器不会报错，但它会把5赋给a，然后判断a是否为真（非零），结果永远是true，逻辑就全乱套了。

int score = 85;
int passLine = 60;
int isPass = (score >= passLine);  // isPass 得到 1（true）
int isPerfect = (score == 100);    // isPerfect 得到 0（false）

逻辑运算符

&emsp;&emsp;有了关系运算符，我们只能做单一条件的判断，但现实世界中往往需要多个条件组合，比如“天气晴朗并且气温适宜”或者“用户是管理员或者是超级用户”。这时候逻辑运算符就派上用场了。逻辑运算符用于连接多个布尔表达式，结果也是布尔值。

运算符 含义 说明
&& 逻辑与 两边都为真时结果为真，否则为假
|| 逻辑或 两边至少有一个为真时结果为真，否则为假
! 逻辑非 真变假，假变真

&emsp;&emsp;逻辑运算符有一个“短路”特性：对于 &&，如果左边已经为假，右边就不再计算；对于 ||，如果左边已经为真，右边也不再计算。这个特性在编程中经常被用来做条件保护，比如 if (p != NULL && p->value > 0) 就不会因为空指针而崩溃。

int age = 25;
int hasLicense = 1;  // 1 表示 true
int canDrive = (age >= 18) && hasLicense;  // 结果为 1（true）
int isTeen = (age < 13) || (age > 19);     // 结果为 0（false），因为 25 不在 13~19 之间
int isNotAdult = !(age >= 18);             // 结果为 0（false），因为 age>=18 为真，取反为假

自增与自减运算符

&emsp;&emsp;在编程中，我们经常需要对变量进行“加1”或“减1”的操作，比如循环计数。C语言为这种常见需求提供了简洁的自增运算符 ++ 和自减运算符 --。它们可以放在变量的前面（前缀）或后面（后缀），但效果略有不同：

  • 前缀(++i 或 --i): 先自增/自减，再使用该变量的值。
  • 后缀(i++ 或 i--): 先使用该变量的当前值，再自增/自减。
  • &emsp;&emsp;如果单独写成一条语句，比如 i++;，前缀和后缀没有区别，都是让 i 加1。但当你把它放在表达式中时，区别就来了：
    int count = 5;
    int result1 = ++count;  // count 先变为 6，然后赋给 result1，所以 result1=6，count=6
    int result2 = count--;  // 先把 count 的当前值（6）赋给 result2，然后 count 减为 5，所以 result2=6，count=5

复合赋值运算符

&emsp;&emsp;你有没有觉得 i = i + 5 这种写法有点啰嗦？明明是想让 i 增加5，却要把它写两遍。C语言贴心地提供了复合赋值运算符，将算术运算和赋值合并在一起，既简洁又高效。

运算符 等价于
+= a = a + b
-= a = a - b
*= a = a * b
/= a = a / b
%= a = a % b

&emsp;&emsp;这个部分其实并不难理解，只要看了下面实例就一定能理解。

int total = 10;
total += 5;   // total 变为 15
total *= 2;   // total 变为 30
total %= 7;   // total 变为 2（30 除以 7 余 2）

运算符优先级与结合性

&emsp;&emsp;讲了这么多运算符，那它们放在一起时，谁先算谁后算呢？这就像数学里的“先乘除后加减”一样，C语言也有自己的一套优先级规则。优先级高的运算符先执行，优先级相同的则根据结合性（从左到右或从右到左）决定顺序。完整的优先级表比较复杂，但记住几个常用的就够用了：

  1. 括号 () 永远优先级最高——如果搞不清顺序，就用括号强行指定，这是最稳妥的做法。
  2. 自增/自减、取地址、逻辑非等单目运算符优先级很高
  3. 算术运算符（* / % 高于 + -）
  4. 关系运算符（> < >= <= 高于 == !=）
  5. 逻辑运算符（&& 高于 ||）
  6. 赋值运算符（= 及复合赋值）优先级最低

&emsp;&emsp;下面是一个混合运算的例子，我们用括号把优先级写清楚，帮助理解：

int a = 5, b = 10, c = 3;
int result = a + b * c - (b / a);  // 实际上等价于 a + (b*c) - (b/a)
// 计算过程：b*c=30，b/a=2，所以 result = 5 + 30 - 2 = 33

&emsp;&emsp;如果你对优先级没有十足把握，大胆地用括号——括号既不会影响运行效率，还能让代码读起来一目了然，何乐而不为呢？

从“借用外力”说起：什么是 #include

&emsp;&emsp;我们前两节聊了变量和运算符，它们是程序的血肉和动作。但一个C程序光有这些还不够，我们总得跟外界打交道——比如向屏幕输出文字（printf），或者从键盘读取输入（scanf）。这些功能并不是C语言“天生自带”的，而是通过别人写好的库函数提供的。

&emsp;&emsp;那怎么告诉计算机，我们想用这些现成的工具呢？答案就是 #include。它是一个预处理指令（Preprocessor Directive），作用简单粗暴：把指定文件里的所有内容，原封不动地复制粘贴到这一行所在的位置。你可以把它想象成一个“抄写员”，在编译真正开始之前，先把我们需要的外部代码整整齐齐地抄进我们的源文件里。

注意：以 # 开头的语句都是预处理指令，它们不是C语言的可执行语句，不以分号结尾。这些指令在编译器进行真正的语法分析之前就会被处理掉。

#include 的两种“请人”方式

&emsp;&emsp;既然是要“抄”文件过来，那总得知道文件在哪吧？C语言针对不同的查找范围，提供了两种截然不同的写法：

1. 尖括号形式 —— #include <文件名>

&emsp;&emsp;这种形式告诉编译器：去系统指定的标准库目录里找。这个目录通常是编译器安装时自带的“官方工具箱”，里面存放着C语言标准库的头文件。

#include <stdio.h>   // 去系统目录找 stdio.h
#include <math.h>    // 去系统目录找 math.h

2. 双引号形式 —— #include “文件名”

&emsp;&emsp;这种形式告诉编译器：先在当前源文件所在的目录找，如果找不到，再去系统标准库目录里碰碰运气。这种写法通常用来包含我们自己写的头文件。

#include "myMath.h"   // 优先在当前项目文件夹找 myMath.h
#include "utils.h"    // 优先在当前项目文件夹找 utils.h

&emsp;&emsp;日常使用中，如果引用的是C语言官方自带的库(比如 stdio.h、stdlib.h)，我们就用尖括号；如果是自己项目里和别人一起写的头文件，就用双引号。记住这个惯例，能给编译器省不少找路的功夫。

头文件(.h)里到底装了些什么？

&emsp;&emsp;你可能会好奇，我们费劲包含进来的 .h 文件里，写的到底是个啥？简单来说，头文件里装的主要是函数的声明、宏定义、类型定义和全局变量的外部声明。

&emsp;&emsp;打个比方：如果函数的具体实现是一本厚厚的“武功秘籍”(一般放在 .c 文件里)，那 .h 头文件就是这本秘籍的目录——它告诉你里面有哪些招式(函数名)、需要准备什么兵器(参数类型)、打出去会有什么效果(返回值类型)，但具体怎么运功发力(函数体)，你暂时不需要知道，那是链接器的事。

基础阶段常用头文件

&emsp;&emsp;C语言标准库提供了很多头文件，每一个都管理着一类特定的工具。下面这几个是你入门阶段打交道最多的“老朋友”：

头文件 最常用的功能
stdio.h 标准输入输出(printf 输出、scanf 输入、文件读写等)
stdlib.h 标准库工具(内存分配 malloc、随机数 rand、程序退出 exit 等)
string.h 字符串处理(拷贝 strcpy、连接 strcat、比较 strcmp、求长度 strlen)
math.h 数学运算(sin、cos、sqrt 开平方、pow 幂运算等)
ctype.h 字符类型判断(判断字母 isalpha、判断数字 isdigit、大小写转换等)
time.h 时间与日期(获取当前时间 time、格式化时间等)

&emsp;&emsp;只要你想使用上面表格里列出的函数，就必须在文件顶部加上对应的 #include。如果漏掉了，编译器在编译时会给你抛出一个“隐式声明”(Implicit Declaration)的警告或错误，本质上就是编译器没见过这个函数，不知道该怎么处理。

重复包含的问题

&emsp;&emsp;如果你的项目变得很大，出现了 A.h 包含了 B.h，而 C.c 同时又包含了 A.h 和 B.h，那么 B.h 的内容可能被编译器抄了两次——重复定义会导致编译报错。

&emsp;&emsp;为了解决这个问题，C语言社区有一种通用的写法，叫****头文件守卫(Header Guard)**。在你自己写的头文件里，可以这样写:

#ifndef MY_HEADER_H
#define MY_HEADER_H

int linkCanAddTwoNumbers(int a, int b);

#endif

&emsp;&emsp;#ifndef 的意思是“如果没有定义某个宏”，就执行下面的内容，并定义这个宏。这样即使这个头文件被多次 #include，编译器也只会真正“抄”一次，后面的全部被跳过，完美避免了重复定义的尴尬。

预处理器的工作原理

&emsp;&emsp;当你按下编译按钮时，预处理器的第一个动作就是读入 stdio.h 文件，把它那几百行声明代码(里面可能还包含了其他头文件)一股脑地插入到 main.c 的最前面。然后，预处理器才会把这“合并后的巨型文件”丢给真正的编译器去进行词法分析和语法分析。

&emsp;&emsp;所以，#include 本质上就是一场发生在编译前的“文本级合并”，它不追求效率，只追求准确无误地把所有依赖的外部声明原样搬进来。

stdio.h —— C语言的输入输出之门

&emsp;&emsp;我们在上一节已经认识了 #include 预处理指令，也知道了 stdio.h 是C语言标准库中最常用的头文件之一。但 stdio.h 里面到底有什么？它凭什么能让我们在黑色的控制台里看到文字、敲入数字？

什么是 stdio.h？

&emsp;&emsp;stdio.h 是 Standard Input Output 的头文件缩写，翻译过来就是“标准输入输出库”。它里面声明了C语言用来做输入输出操作的各种函数、宏和类型定义。简单来说，如果你想在控制台打印东西(输出)或者让用户从键盘敲东西进来(输入)，就必须在代码最前面写上：

#include <stdio.h>

&emsp;&emsp;你可能会问：为什么不能直接写 printf 而要包含这个文件？因为 printf 这个函数的“使用说明书”（也就是函数原型）就存放在 stdio.h 里。编译器在编译你的代码时，需要看到这份说明书才知道 printf 长什么样——它接受什么参数、返回什么类型。如果没有 #include <stdio.h>，编译器就会一脸茫然地报出“隐式声明”的警告或错误。

三大标准流：stdin、stdout、stderr

&emsp;&emsp;在C语言的世界里，输入输出被抽象成了流（stream） 的概念。你可以把“流”想象成一根管道，数据就像水一样在管道里流动。C语言程序启动时，系统会自动为你打开三根管道：

流名称 对应设备 作用
stdin 键盘（默认） 标准输入流，程序从这里读取数据
stdout 屏幕（默认） 标准输出流，程序从这里输出正常信息
stderr 屏幕（默认） 标准错误流，程序从这里输出错误信息

&emsp;&emsp;printf 默认往 stdout 写，scanf 默认从 stdin 读。stderr 和 stdout 虽然都输出到屏幕，但它们是分开的——这样做的好处是，即使你重定向了正常的输出内容，错误信息依然能独立显示出来，不会被混进数据文件里。

printf —— 格式化输出函数

&emsp;&emsp;printf 应该是你在C语言里遇到的第一个函数，也是用的最多的一个。它的名字末尾的 f 代表 format（格式化），意思是它可以按照你指定的格式来输出数据。

printf 的基本调用格式

printf("格式控制字符串", 输出项1, 输出项2, ...);

&emsp;&emsp;格式控制字符串里可以包含三类内容：

  1. 普通字符：原样输出，比如 "Hello" 就直接打印 Hello
  2. 转换说明符：以 % 开头，用来控制后面输出项的显示格式，比如 %d、%f
  3. 转义字符：以 \ 开头，比如 \n 换行、\t 制表符

常用格式说明符（类型字符）

&emsp;&emsp;格式说明符的基本结构如下：

%[标志][宽度][.精度][长度修饰符]类型

&emsp;&emsp;其中类型是唯一必须的部分，其他都是可选的。下表列出了最常用的类型字符：

格式符 对应数据类型 说明
%d 或 %i int 有符号十进制整数
%u unsigned int 无符号十进制整数
%o unsigned int 无符号八进制整数
%x / %X unsigned int 无符号十六进制整数（小写/大写）
%f float / double 浮点数（小数形式），默认6位小数
%e / %E float / double 浮点数（指数形式）
%g / %G float / double 根据数值自动选 %f 或 %e，不输出无意义零
%c char 单个字符
%s char* 字符串
%p void* 指针地址
%% 无 输出一个百分号 
int age = 25;
float pi = 3.14159;
char grade = 'A';
char name[] = "Alice";

printf("年龄: %d\n", age);          // 输出: 年龄: 25
printf("圆周率: %f\n", pi);         // 输出: 圆周率: 3.141590
printf("等级: %c\n", grade);        // 输出: 等级: A
printf("名字: %s\n", name);         // 输出: 名字: Alice

Warning：printf 中 %f 既可以输出 float 也可以输出 double，因为 float 在传参时会自动提升为 double。但 scanf 中 %f 和 %lf 是严格区分的，后面会讲到。

宽度（Width）

&emsp;&emsp;宽度指定了输出字段的最小宽度。如果实际数据的长度小于这个宽度，默认会在左边补空格（右对齐）；如果大于宽度，则按实际长度输出。

int a = 123;

printf("%5d\n", a);    // 输出: "  123"（默认右对齐，左边补2个空格）
printf("%1d\n", a);    // 输出: "123"（宽度小于实际长度，全部输出）
printf("%5d\n", a);     // 默认右对齐，且最少取5位整数，多余5位全取，不足5位使用空格左面补全
printf("%-5d\n", a);    // 左对齐，不足位数，使用空格补全

标志字符（Flags）

&emsp;&emsp;标志字符用来调整输出的对齐和填充方式，放在 % 和宽度之间：

标志 含义 示例
- 左对齐（默认右对齐） %-10d
+ 强制显示正负号 %+d
空格 正数前显示空格，负数显示负号 % d
0 用零填充空位（而非空格） %05d
# 使用替代格式（如八进制前加0，十六进制前加0x） %#x 
int num = 123;

printf("%-10d\n", num);    // 输出: "123       "（左对齐）
printf("%+d\n", num);      // 输出: "+123"
printf("% d\n", num);      // 输出: " 123"（正数前有个空格）
printf("%05d\n", num);     // 输出: "00123"（用0填充）
printf("%#x\n", num);      // 输出: "0x7b"
printf("%05d\n", a);    // 使用0代替空格，在左边补齐位数
printf("%-05d\n", a);   // 左对齐，不足位数，还是用空格补全（0标志在左对齐时失效）

精度（Precision）

&emsp;&emsp;精度以 . 开头，后面跟一个数字，它的含义取决于格式化的是什么类型：

  • 浮点数：指定小数点后保留几位小数（会四舍五入）
  • 字符串：指定最多输出几个字符
  • 整数：指定最少输出几位数字（不足补零）
float pi = 3.14159;
float num = 3.14159;
char str[] = "HelloWorld";

printf("%.2f\n", pi);      // 输出: 3.14（保留2位小数）
printf("%.3f\n", num);     // 输出: 3.142（保留3位小数，四舍五入）
printf("%.5s\n", str);     // 输出: "Hello"（只取前5个字符）
printf("%.2f\n", a);   // 取2位小数，且第三位四舍五入
printf("%.3f\n", b);   // 取3位小数，且不足的用0补全

宽度与精度组合

&emsp;&emsp;宽度和精度可以同时使用，格式是 %[宽度].[精度]类型：

float b = 12.3;

printf("%4.2f\n", b);    // 至少4位字符，2位小数 → 输出 "12.30"
printf("%7.2f\n", b);    // 至少7位字符，2位小数 → 输出 "  12.30"

&emsp;&emsp;%4.2f 的含义是：总共至少占4个字符宽度，其中小数点后保留2位。12.30 一共是5个字符（1、2、.、3、0），已经超过了4，所以全部输出。%7.2f 则因为7 > 5，左边补了2个空格。

字符串的宽度与精度

&emsp;&emsp;字符串的格式控制稍微特殊一点：

char s1[] = "abc";

printf("%s\n", s1);        // 输出: "abc"
printf("%2s\n", s1);       // 输出: "abc"（宽度2小于实际长度，全部输出）
printf("%5s\n", s1);       // 输出: "  abc"（宽度5，左边补2个空格）
printf("%-5s\n", s1);      // 输出: "abc  "（左对齐，右边补2个空格）
printf("%4.2s\n", s1);     // 输出: "  ab"（总宽4，但只取前2个字符，左边补空格）
printf("%.2s\n", s1);      // 输出: "ab"（只取前2个字符）

printf 的返回值

&emsp;&emsp;printf 其实是有返回值的——它返回成功输出的字符总数，如果出错则返回负数。虽然大多数时候我们忽略这个返回值，但在某些需要检查输出是否成功的场景下，它是有用的。

sprintf 函数

&emsp;&emsp;sprintf 函数可以让你格式化好一个字符串而不直接输出到控制台上,以下是其函数定义:

int sprintf(char *str, const char *format, [argument,...]);

&emsp;&emsp;我承认这样作为一个初学者可能很难看懂，不过我还是找到了好的例子:

char str[30];
float tall = 170.6777777;
sprintf(str, "Link's tall is %.2f\n", tall);
printf("%s", str);
// 最终输出结果为: Link's tall is 170.68
// 某种意义上很成功的美化了我的身高(增加了0.01cm)

scanf —— 格式化输入函数

&emsp;&emsp;有输出就得有输入。scanf 就是 printf 的“好兄弟”——它负责从键盘读取用户输入的数据，并按照你指定的格式存到变量里。

scanf 的基本调用格式

scanf("格式控制字符串", &变量1, &变量2, ...);

&emsp;&emsp;注意！scanf 的参数是变量的地址，而不是变量本身。这就是为什么要在变量名前加 &（取地址符）。

int age;
scanf("%d", &age);   // 正确：传入age的地址
// scanf("%d", age); // 错误！传入的是age的值（一个随机数），程序会崩溃

scanf 的格式说明符

&emsp;&emsp;scanf 的格式说明符和 printf 大致相同，但有一个重要的区别：**scanf 必须严格区分 %f 和 %lf**。

格式符 对应变量类型 说明
%d int* 有符号十进制整数
%u unsigned int* 无符号十进制整数
%o unsigned int* 无符号八进制整数
%x unsigned int* 无符号十六进制整数
%f float* 单精度浮点数（注意：是 float*，不是 double*）
%lf double* 双精度浮点数
%c char* 单个字符
%s char* 字符串（不含空格）

读取单个值

int number;
printf("请输入一个整数: ");
scanf("%d", &number);
printf("你输入了: %d\n", number);

&emsp;&emsp;程序运行到 scanf 时会停下来，等待你在键盘上输入并按下回车键。输入的数据会被转换并存储到 number 变量对应的内存单元中。

读取多个值

&emsp;&emsp;scanf 可以在一次调用中读取多个数据，格式字符串里按顺序写好对应的说明符即可：

int age;
float height;
char initial;

printf("请输入年龄、身高和姓名首字母（空格隔开）: ");
scanf("%d %f %c", &age, &height, &initial);
printf("年龄: %d, 身高: %.2f, 首字母: %c\n", age, height, initial);

&emsp;&emsp;用户在输入时可以用空格、Tab或回车来分隔不同的数据。

读取字符串时的注意事项

&emsp;&emsp;用 %s 读取字符串时要特别小心——scanf 不会检查目标数组的大小，如果用户输入的内容超过了数组长度，就会发生缓冲区溢出，这是非常严重的安全隐患。

&emsp;&emsp;安全的做法是指定最大读取宽度：

char name[50];
scanf("%49s", name);   // 最多读取49个字符（留1个给结尾的'\0'）

&emsp;&emsp;另外，%s 遇到空格就会停止读取，所以如果你想读取带空格的整行文字（比如 “Alice Wang”），%s 只能读到 “Alice”。这时候可以用 fgets 代替，不过那是后话了。

scanf 的返回值

&emsp;&emsp;scanf 返回成功读取并赋值的参数个数。这是一个非常实用的特性——你可以通过检查返回值来判断用户是否输入了正确数量的数据：

int age;
int result = scanf("%d", &age);
if (result != 1) {
    printf("Invalid input!\n");
    return 1;
}

&emsp;&emsp;如果用户输入的不是数字（比如输入了 “abc”），scanf 会读取失败，返回0，你就可以捕获这个错误并做出相应处理。

字符级输入输出函数

&emsp;&emsp;除了 printf 和 scanf 这种格式化输入输出，stdio.h 还提供了一些更底层的、按字符操作的函数：

函数 作用
getchar() 从标准输入读取一个字符
putchar(int c) 向标准输出写入一个字符
puts(const char* s) 输出一个字符串并自动换行 
char ch;
ch = getchar();        // 从键盘读一个字符
putchar(ch);           // 把这个字符打印到屏幕
puts("Hello!");        // 打印 "Hello!" 并换行

&emsp;&emsp;这些函数虽然简单，但在某些场景下比 printf/scanf 更高效、更灵活——比如你需要逐个字符处理输入，或者只想简单地打印一行文字而不需要格式化。
